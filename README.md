# HARMONYA MEDICAL — Site web

Site vitrine de l'agence de promotion de produits pharmaceutiques **HARMONYA MEDICAL**, développé avec Next.js.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — serveur de développement
- `npm run build` — build de production
- `npm run start` — lancer le build de production
- `npm run lint` — lint ESLint

## Structure

```
src/
  app/                 # Layout & page d'accueil
  components/
    layout/            # Header, Footer, Logo
    sections/          # Sections de la landing
    ui/                # Boutons, icônes, utilitaires
public/
  logo.png             # Logo officiel
```
